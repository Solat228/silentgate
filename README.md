SilentGate — VPN-клиент для Windows и Android: VLESS/Reality и Hysteria2 под одним
интерфейсом, без стороннего приложения и его рекламы.

**[⬇ Скачать последнюю версию](https://github.com/Solat228/silentgate/releases/latest)** —
установщик (`SilentGateSetup-*.exe`) или портативная сборка (`SilentGate-Portable-*.zip`)
для Windows, `.apk` для Android.

> ⚠️ Бета. Первый таргет — Windows, следом идёт Android.

## Установка

**Windows** — скачайте `SilentGateSetup-*.exe` и запустите: мастер сам спросит язык и
поставит приложение. Не хочется ставить — берите `SilentGate-Portable-*.zip`,
распакуйте и запускайте `silentgate.exe` из папки.

**Android** — скачайте `.apk` под архитектуру вашего телефона (arm64-v8a — почти все
современные устройства) и установите. Разрешите установку из неизвестных источников,
если система попросит.

Дальше — импортируйте свою ссылку подписки или сервера (кнопка «Импорт» при первом
запуске) и подключайтесь.

## Обновление

Приложение само проверяет GitHub Releases и подсказывает, когда вышла новая версия —
никакого файла оно за вас не скачивает и не ставит. На Windows установщик новой версии
сам закрывает запущенное приложение и обновляет его на месте; на Android — обычная
переустановка `.apk` поверх старой версии.

## Поддержка

Что-то не работает — в приложении есть кнопка «Поддержка» (Настройки → О программе):
она собирает диагностический отчёт (версии, настройки, логи, без паролей и адресов
серверов) и подсказывает, куда его отправить.

Баг в самом клиенте или пожелание — заводите
[issue в этом репозитории](https://github.com/Solat228/silentgate/issues).

## Что нового

Версию показывает бейдж выше — он читает последний релиз и не устаревает сам по себе.
Полная история — **[CHANGELOG.md](CHANGELOG.md)**.

### 1.13.0 — установщик закрывает приложение сам, бета-канал и откат версии

Установщик больше не отправляет человека в трей руками: VPN выключен — закроет молча, VPN
активен — спросит, рвать ли соединение. У обновлений появился отдельный бета-канал по галочке
(по умолчанию выключен) и откат на прежнюю версию. Блок проверок перестал прятать низ главного
экрана: сетка стала 2 колонки на сторону, легенда уехала в подсказку, значки выросли с 18,8 до
28 px. Кнопка подбора сервера переехала к списку серверов и называется глаголом — на экране
больше не три разных «авто».

### 1.12.0 — запас у прямого DNS и запасной путь у выхода

Две подсистемы про то, что раньше молча переставало работать: у резолва трафика
«Прямо» не было запаса (65 % всех ошибок ядра в журнале круглосуточного клиента),
а у выхода раздельного туннелирования — запасного пути. Плюс сторож выходов
больше не выносит приговор вчетверо быстрее положенного.

## Технически

Один Flutter/Dart-интерфейс на все платформы, движок — **Xray-core** (VLESS/XTLS/Reality)
плюс **sing-box** отдельным процессом для TUN-режима и Hysteria2. Оба ядра — отдельные
бинарники, не линкуются в приложение. Подробное обоснование стека, архитектура и
поэтапный план по платформам — в [docs/STACK_DECISION.md](docs/STACK_DECISION.md),
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) и [docs/ROADMAP.md](docs/ROADMAP.md).

### Сборка из исходников (Windows)

```powershell
# 1. Flutter SDK (см. tools/bootstrap-windows.ps1)
# 2. Ядро xray.exe в engine/windows/bin/
powershell -ExecutionPolicy Bypass -File tools/fetch-xray.ps1
# 3. Запуск
cd app
flutter pub get
flutter run -d windows
```

Подробности разработки Windows-версии — [docs/platforms/WINDOWS.md](docs/platforms/WINDOWS.md).
