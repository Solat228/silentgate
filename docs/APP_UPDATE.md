# Автообновление приложения

Как SilentGate узнаёт о новой версии себя. Не путать с обновлением **подписки** —
про него отдельный документ `SUBSCRIPTION_UPDATE.md`.

## Поведение в приложении

При запуске (если включено в настройках) приложение делает один GET на эндпоинт версии.
Если пришедшая версия **новее текущей** — всплывает уведомление с кнопкой «Скачать»,
которая открывает ссылку в браузере.

**Приложение НИЧЕГО не скачивает и не запускает само.** Это осознанное решение:
установщик не подписан сертификатом, и самозапуск скачанного exe упирается в SmartScreen
и выглядит для антивирусов ровно как поведение зловреда. Пользователь скачивает и ставит
обновление сам.

Если эндпоинта нет или он недоступен — приложение молча продолжает работу, запись уходит
только в лог. Никаких ошибок пользователю: отсутствие сервера обновлений это не поломка.

## Что нужно на сервере

`GET https://silentgate.lol/api/app-version` → JSON:

```json
{
  "version": "0.9.0",
  "url": "https://silentgate.lol/download/SilentGateSetup-0.9.0.exe",
  "notes": "Мульти-подписки и экран информации о сервере"
}
```

| Поле | Обязательно | Смысл |
|---|---|---|
| `version` | да | Версия вида `x.y.z`. Сравнивается почислово; суффиксы (`-beta`) игнорируются |
| `url` | нет | Ссылка на установщик. Без неё уведомление покажется без кнопки «Скачать» |
| `notes` | нет | Короткая строка «что нового» — попадёт в текст уведомления |

Адрес эндпоинта меняется в настройках приложения (раздел «О программе»), так что можно
держать его где угодно — хоть на GitHub Releases, хоть статическим файлом.

### Nginx (статический файл)

```nginx
location = /api/app-version {
    default_type application/json;
    add_header Cache-Control "no-store";
    alias /var/www/silentgate.lol/api/app-version.json;
}
```

Выпуск новой версии = правка одного файла:

```bash
cat > /var/www/silentgate.lol/api/app-version.json <<'EOF'
{"version":"0.9.0","url":"https://silentgate.lol/download/SilentGateSetup-0.9.0.exe","notes":"Что нового"}
EOF
```

## ⚠️ Текущее состояние (проверено 22.07.2026)

Домен `silentgate.lol` **не отвечает по HTTP** (DNS резолвится в `213.176.119.223`, но
соединение не устанавливается). Работает только `sub.silentgate.lol/sub/<id>`; на корне
и на `/assets/*` этого хоста — **502**.

Это значит, что сейчас не работают:
- проверка обновлений приложения (этот документ);
- «пуш»-обновление подписки через version-эндпоинт (`SUBSCRIPTION_UPDATE.md`);
- страница подписки в браузере и её логотип (`RU_ROUTING_SOURCES.md` — там же про 502).

Приложение к этому готово: обе проверки при недоступности сервера просто молчат. Но пока
сайт не поднят, автообновление физически не может работать.
