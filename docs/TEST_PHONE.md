# Проверка на телефоне — что гонять владельцу

Живой прогон на настоящем телефоне делает владелец; эмулятор и VM я гоняю сам, но телефон они
не заменяют (другая сеть, Doze, производитель, настоящий оператор). Здесь — что проверить и
что прислать, если не работает. Документ обновляется к каждой версии: сверху — текущая.

## Как присылать результат

- **Работает** — достаточно «пункт N ок».
- **Не работает** — словами: что жал, что ждал, что увидел. Плюс журнал:
  Настройки → Поддержка → «Сгенерировать лог для поддержки» → поделиться файлом.
  Время сбоя (хотя бы примерно) — очень помогает найти место в журнале.
- Скрин экрана, если что-то выглядит не так.
- В журнале адреса серверов уже замаскированы, токен подписки не пишется — его можно слать как есть.

## 1.14.0 (бета)

### Обновление с прежней версии
1. Поставить APK 1.14.0 поверх 1.13.x (не удаляя). Подписки, выбранный сервер, правила
   раздельного туннелирования — на месте.
2. Настройки → «Обновления»: видна версия 1.14.0 и канал. Кнопка «Проверить» отвечает
   «установлена последняя» (или предлагает новую, если к тому времени вышла).

### Самообновление (главное в версии)
Проверить можно только когда выйдет следующая версия после 1.14.0 — тогда:
3. Приложение само предлагает обновиться (режим «спрашивать» по умолчанию).
4. Первый раз Android попросит разрешение «Установка неизвестных приложений». ⚠️ После выдачи
   разрешения Android сам перезапускает приложение — это нормально. Ожидается: при следующем
   открытии обновление продолжается само, повторно жать «Обновить» не нужно.
5. Системное окно установки → «Обновить» → приложение открывается уже новой версией,
   подписки целы.

### Внешний вид
6. Строка сервера в списке — плотнее, флаг поменьше (вариант «Б»).
7. Подписи групп у кнопки подключения («Мессенджеры», «ИИ»…) — крупнее, читаются без
   напряжения, все одного размера.
8. Двойные флаги у серверов (например «США → Германия») — каждый флаг узнаётся.

### Подключение (регресс — должно работать как раньше)
9. Подключиться к обычному серверу → работает **дольше минуты**, сайты открываются.
10. Подключиться к «Авто» от панели → работает, пинг даёт числа.
11. hysteria2-сервер → работает.
12. Отключиться → значок VPN в строке состояния пропал. ⚠️ Раньше было: VPN «не снимался».
    Засечь, сколько секунд занимает отключение (раньше было долго, ~12 с).
13. Выключить и включить Wi-Fi / перейти на мобильный интернет при подключённом VPN →
    туннель переподнимается сам, уведомление о кратком обрыве допустимо.
14. Свернуть приложение на 10+ минут с включённым VPN, экран погашен → по возвращении
    VPN жив, трафик идёт.

### Раздельное туннелирование
15. Правило «сайт → через VPN», остальное напрямую: 2ip.ru показывает VPN, другой сайт
    проверки IP — реальный адрес.
16. Мульти-выход: разные сайты через разные серверы (например 2ip.ru через США,
    YouTube через Нидерланды) — каждый сайт показывает свою страну.
17. Импорт правил из буфера (новое): скопировать экспорт правил, вставить — правила появились,
    старые не потерялись.

### Сообщение от сервера
18. Если провайдер присылает текстовое сообщение вместо серверов (истёкшая подписка) —
    флаги-эмодзи в нём видны картинками, длинный текст обрезан с «…» и раскрывается по нажатию,
    «Скопировать» копирует весь текст.

### Чего в 1.14.0 не проверяем
- Локальный API на телефоне — поддерживается, но не тестируется (ждём issues на GitHub).
- Автонастройка на Android — ещё не сделана.
