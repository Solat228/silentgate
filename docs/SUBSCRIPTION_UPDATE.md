# Автообновление подписки и «пуш» с сайта (пункт 4)

Как SilentGate обновляет подписку и как вы можете **триггерить обновление у всех клиентов** со своего сайта
(`silentgate.lol`), не дожидаясь интервала.

## Как работает в приложении
1. **По интервалу.** После импорта приложение периодически (по заголовку `profile-update-interval` подписки, по
   умолчанию 12 ч) перекачивает подписку и обновляет список серверов. Управляется настройкой «Автообновление подписки».
2. **По version-эндпоинту (пуш).** Каждые ~10 минут приложение опрашивает эндпоинт версии на вашем сайте. Если
   значение `version` изменилось с прошлой проверки — подписка обновляется **сразу** (и опционально показывается
   `message`). Реализация в `app/lib/core/subscription/subscription_updater.dart` (URL по умолчанию —
   `https://silentgate.lol/api/version`).

## Что нужно на сайте: эндпоинт версии
`GET https://silentgate.lol/api/version` → JSON:
```json
{ "version": "2026-07-19T12:00", "message": "Список серверов обновлён" }
```
- **version** — любая строка (число, дата, хэш). Клиент запоминает её; при **любом изменении** обновляет подписку.
- **message** — необязательно; показывается пользователю после обновления.

Чтобы заставить всех обновиться прямо сейчас — **измените `version`** (например, поставьте текущую дату/время или
инкремент). Клиенты в течение ~10 минут подхватят.

## Варианты реализации (от простого к гибкому)

### A. Статический файл (проще всего)
Положите файл и правьте его руками/скриптом, когда меняете серверы:
```
# /var/www/silentgate.lol/api/version   (или version.json)
{ "version": "3", "message": "Обновите список серверов" }
```
Nginx: отдавать как есть с `Content-Type: application/json` и без кэша:
```nginx
location = /api/version {
    default_type application/json;
    add_header Cache-Control "no-store";
    alias /var/www/silentgate.lol/api/version.json;
}
```
Обновить у всех: `echo '{"version":"'$(date +%s)'"}' > /var/www/silentgate.lol/api/version.json`.

### B. PHP (динамически из панели/БД)
```php
<?php // /api/version.php
header('Content-Type: application/json');
header('Cache-Control: no-store');
// version = время последнего изменения набора серверов (из БД/файла-флага)
$ts = @filemtime('/var/lib/silentgate/servers.flag') ?: time();
echo json_encode(['version' => (string)$ts, 'message' => '']);
```
Когда меняете серверы в панели — `touch /var/lib/silentgate/servers.flag` (или обновляйте запись в БД). Все клиенты
обновятся.

### C. Через сам заголовок подписки (без отдельного эндпоинта)
Если проще — можно не делать эндпоинт, а полагаться только на интервал (вариант 1). Тогда просто держите разумный
`profile-update-interval` в ответе панели (Remnawave это уже отдаёт).

## Настройка URL в приложении
Сейчас URL эндпоинта задан по умолчанию (`https://silentgate.lol/api/version`). Если путь другой — поменяйте
`versionUrl` в `SubscriptionUpdater` (позже вынесем в настройки при необходимости).

## Безопасность
- Эндпоинт **не содержит секретов** — только строку версии; отдавать публично безопасно.
- Не кладите в `message` ссылки на оплату для iOS-сборки (правила Apple) — это только для десктопа/Android.
