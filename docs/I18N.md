# Локализация (i18n)

Интерфейс переводится через официальный механизм Flutter — `flutter_localizations`
+ `gen_l10n` (ARB-файлы). Без сторонних зависимостей, с проверкой ключей на компиляции.

## Как устроено

- **База — русский.** Шаблон: `app/lib/l10n/app_ru.arb` (в нём же `@`-описания ключей).
- Переводы: `app/lib/l10n/app_en.arb`, `app_es.arb` (и далее по языку на файл).
- Конфиг кодогена: `app/l10n.yaml`. Генерит **реальные** файлы в
  `app/lib/l10n/gen/app_localizations*.dart` (не синтетический пакет — так они
  переживают сборку через junction и коммитятся в репозиторий).
- Список языков (для меню и флагов): `app/lib/core/i18n/app_locales.dart`.
- Выбранный язык хранится в `AppSettings.languageCode` (`''` = следовать системе),
  прокинут в `MaterialApp.locale` (`app/lib/app.dart`).
- Переключатель — `LanguageButton` в шапке экрана настроек (значок перевода + флаг
  текущего языка, стиль Google Переводчика).

## Использование в коде

```dart
import '../l10n/gen/app_localizations.dart';

final l = AppLocalizations.of(context);
Text(l.settingsTitle);
```

`nullable-getter: false` → `AppLocalizations.of(context)` не бывает null (кидает,
если делегат не подключён; он подключён в `MaterialApp`).

## Добавить строку

1. Добавь ключ в **`app_ru.arb`** (с `@key` — описанием для переводчиков).
2. Добавь тот же ключ в `app_en.arb`, `app_es.arb`.
3. Перегенерируй: `cd app && flutter gen-l10n` (или это сделает `flutter build`,
   т.к. в pubspec `generate: true`).
4. Замени хардкод-строку на `AppLocalizations.of(context).<key>`.

Плейсхолди/множественное число — стандартным синтаксисом ARB (ICU), например:
```json
"serversCount": "{count, plural, one{{count} сервер} few{{count} сервера} other{{count} серверов}}",
"@serversCount": { "placeholders": { "count": { "type": "int" } } }
```

## Добавить язык (быстро)

Один скрипт-заготовка + две строки:

```
cd app
dart run tool/scaffold_locale.dart <code> [ISO-страна]   # напр.: de DE
# → создаст lib/l10n/app_<code>.arb со ВСЕМИ ключами (значения = ru-заготовки,
#   тест паритета сразу зелёный, язык «работает», показывая русский до перевода)
```

Затем:
1. Добавь строку в `supportedLanguages` (`app/lib/core/i18n/app_locales.dart`):
   `AppLanguage('<code>', '<самоназвание>', '<ISO-страна для флага>')`.
2. `flutter gen-l10n`.
3. Переведи значения в `app/lib/l10n/app_<code>.arb` (ключи не трогать — их держит
   `test/l10n_test.dart`: паритет с базой `ru`, непустые значения, совпадение плейсхолдеров).

Язык сразу появится в меню `LanguageButton` и в `supportedLocales`.

## Статус миграции

Каркас + переключатель готовы; переведены: заголовок настроек, заголовки разделов
настроек, общие кнопки (отмена/закрыть/копировать/обновить), раздел выбора языка.
**Остальные экраны переводятся инкрементально** тем же паттерном — строка за строкой
переносится из хардкода в ARB. Русские тексты остаются базой (`app_ru.arb`).
